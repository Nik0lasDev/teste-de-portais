# 🔵🟠 Portais 3D

Protótipo 3D em primeira pessoa inspirado na mecânica clássica de **Portal**. O cenário é uma sala em forma de cubo branco, sem móveis ou obstáculos. Escolha onde posicionar os dois portais nas paredes.

## ▶️ Jogar no navegador

**[Clique aqui para testar o jogo](https://nik0lasdev.github.io/teste-de-portais/)**

> É necessária conexão com a internet para carregar o Three.js por CDN. Se a versão ainda não aparecer, atualize a página com **Ctrl + F5** e confira se a publicação do GitHub Pages terminou.

## 🎮 Controles

| Tecla / ação | Função |
| --- | --- |
| **W / A / S / D** | Mover-se |
| **Mouse** | Olhar e mirar |
| **Espaço** | Pular |
| **Clique esquerdo** | Posicionar ou reposicionar o portal azul |
| **Clique direito** | Posicionar ou reposicionar o portal laranja |
| **Esc** | Liberar o mouse |
| **Clique na cena** | Capturar o mouse novamente |

## 🌀 Como testar

1. Abra o jogo e clique em **Entrar no laboratório**.
2. Mire em qualquer ponto de uma parede branca.
3. Clique com o botão esquerdo para colocar o portal azul.
4. Mire em outro ponto — na mesma parede ou em outra — e clique com o botão direito para colocar o portal laranja.
5. Use **WASD** para se movimentar e experimente atravessar os portais.

Por enquanto, os portais podem ser posicionados nas **paredes**; chão e teto não aceitam portais nesta versão.

## ⚠️ Estado do protótipo

A renderização através dos portais e a travessia ainda estão em desenvolvimento. Podem ocorrer falhas de posicionamento, colisão ou movimentação.

## 🧑‍💻 Executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Inicie um servidor HTTP estático na pasta e abra o endereço local no navegador.
4. Mantenha a conexão com a internet para carregar o Three.js.
