# 🔵🟠 Portais 3D

Um protótipo 3D em primeira pessoa inspirado na mecânica clássica de **Portal**. Explore uma sala de testes, coloque dois portais nas paredes e experimente atravessar de um para o outro.

## ▶️ Jogar no navegador

**[Clique aqui para testar o jogo](https://nik0lasdev.github.io/teste-de-portais/)**

Se o link ainda não abrir, verifique se o GitHub Pages terminou de publicar o projeto em **Settings → Pages** e aguarde a conclusão da execução do workflow de publicação.

> É necessário estar conectado à internet, pois o jogo carrega a biblioteca Three.js por CDN.

## 🎮 Controles

| Tecla / ação | Função |
| --- | --- |
| **W / A / S / D** | Mover-se |
| **Mouse** | Olhar ao redor |
| **Espaço** | Pular |
| **Clique esquerdo** | Disparar ou reposicionar o portal azul |
| **Clique direito** | Disparar ou reposicionar o portal laranja |
| **Esc** | Liberar o mouse |
| **Clique na cena** | Capturar o mouse novamente |

## 🌀 Como testar

1. Abra o jogo pelo link acima.
2. Clique na cena para começar a olhar ao redor com o mouse.
3. Mire em uma parede e clique com o botão esquerdo para colocar o portal azul.
4. Mire em outra parede e clique com o botão direito para colocar o portal laranja.
5. Use **WASD** para se movimentar e experimente os portais.

## ⚠️ Sobre esta versão

Este projeto ainda é um **protótipo em desenvolvimento**. A renderização através dos portais e a travessia estão em implementação, então podem existir falhas de posicionamento, colisão ou movimentação. Nem todas as superfícies necessariamente aceitam portais.

## 🧑‍💻 Executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Inicie um servidor HTTP estático na pasta e abra o endereço local no navegador. Também é possível abrir `index.html` diretamente, mas um servidor local costuma ser mais confiável.
4. Mantenha a conexão com a internet para carregar o Three.js.

Sugestões e relatos de bugs são bem-vindos!
